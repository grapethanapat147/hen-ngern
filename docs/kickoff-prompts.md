# Kickoff prompts สำหรับ Claude Code

ใช้ทีละเฟส วาง prompt ของเฟสนั้นแล้วรอให้จบและรายงานก่อนไปเฟสถัดไป

---

## เริ่มโปรเจกต์ (P0 + P1)

```
อ่าน CLAUDE.md และ docs/00 ถึง docs/05 ทั้งหมดก่อน แล้ว:

1. สรุปให้ผมสั้นๆ ว่าเข้าใจ product, สิ่งที่ล็อก และลำดับเฟสว่าอย่างไร
   ถ้าเอกสารขัดกันหรือไม่ชัดตรงไหน ให้ถามก่อนเริ่ม (ไม่เกิน 3 ข้อ)
2. ทำ P0 ตาม docs/04-build-plan.md แล้วอัปเดตส่วน Commands ใน CLAUDE.md
3. ทำ P1: เขียน test ของ Golden Cases G1–G12 และ parser P1–P18 ก่อน แล้วค่อย implement จนผ่านทั้งหมด
   ห้ามแก้ค่าที่คาดหวังใน test เพื่อให้ผ่าน ถ้าคิดว่าเอกสารผิด ให้หยุดแล้วบอกผม
4. รายงานแยก: สร้างอะไร / test อะไรผ่าน / อะไรยังไม่ได้ทำ / ตัดสินใจอะไรไป (บันทึกใน docs/decision-log.md)
```
