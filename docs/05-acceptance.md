# 05 — Acceptance Criteria (v0)

ทุกข้อต้องผ่านที่ **390×844** และ **1280×800** · ข้อที่มี `[e2e]` ต้องมี Playwright spec · Golden Cases อยู่ใน `02-domain-rules.md` §9

## Domain / data

| # | เกณฑ์ |
|---|---|
| A-D1 | Unit tests G1–G12 และ P1–P18 ผ่านทั้งหมด |
| A-D2 | รีเฟรชหน้าแล้วข้อมูลยังอยู่ `[e2e]` |
| A-D3 | ใส่ JSON เสียใน `roongern.v0` → แอปเปิดได้ เป็นสมุดว่าง มีแบนเนอร์ และ raw เดิมถูกสำรอง `[e2e]` |
| A-D4 | ส่งออก JSON แล้วนำเข้ากลับ → ยอดทุกตัวเท่าเดิม |

## ภาพรวมและการจด

| # | เกณฑ์ |
|---|---|
| A-1 | เปิดครั้งแรกเห็น 4 ตัวเลข + แถบพิมพ์ + แบนเนอร์ตัวอย่าง โดยไม่ต้องเลื่อน (390×844) และไม่ต้องสมัคร `[e2e]` |
| A-2 | ทุกจำนวนเงินบนภาพรวมมีป้ายข้อความ *เกิดขึ้นแล้ว* หรือ *คาดว่าจะเกิด* |
| A-3 | พิมพ์ `ได้ค่างาน 4500` → ร่าง income/side → บันทึก → รับจริงและงานเสริมเพิ่ม 4,500 `[e2e]` |
| A-4 | พิมพ์ `จ่าย Netflix 419 ทุกเดือนวันที่ 5 บัตรกสิกร` → กลายเป็นรายการซ้ำ แสดงในรายการซ้ำ, ใกล้ตัด (ถ้าอยู่ใน 7 วัน) และปฏิทิน `[e2e]` |
| A-5 | พิมพ์ `โอน 5,000 จากกสิกรไป SCB` → บันทึก → รับจริง/จ่ายจริงไม่เปลี่ยน `[e2e]` |
| A-6 | พิมพ์ `จ่ายบัตร 8,000` → ปุ่มบันทึกกดไม่ได้จนกว่าจะตอบคำถาม และเลือก "จ่ายยอดบัตร" แล้วจ่ายจริงไม่เปลี่ยน `[e2e]` |

## เงินเข้า-ออก

| # | เกณฑ์ |
|---|---|
| A-7 | ค้นหา + ชิปกรองทำงานร่วมกัน และผลรวมใน header ตรงกับรายการที่เห็น `[e2e]` |
| A-8 | รายการ USD แสดงทั้ง `US$20` และ `≈ ฿665` |
| A-9 | ลบรายการ → ยอดลด → กดเลิกทำ → ยอดกลับเท่าเดิม `[e2e]` |
| A-10 | สร้าง refund ผูกกับรายจ่ายเดิม → จ่ายจริงลดลง และยังเห็นทั้งสองแถว |

## รายการซ้ำ

| # | เกณฑ์ |
|---|---|
| A-11 | กด `จ่ายแล้ว` บน occurrence → จ่ายจริงเพิ่ม, จะตัดอีกลด, นับครั้งเดียว `[e2e]` |
| A-12 | จ่ายจริงต่างจากคาดการณ์ → แสดง diff (`+฿30`) |
| A-13 | จดเอง `Netflix 419` ใกล้วันตัด → มีข้อเสนอจับคู่ · ยืนยันแล้วไม่นับซ้ำ |
| A-14 | การ์ดทดลองแสดง `เหลือ N วัน` และยอดที่จะเริ่มหัก และไม่นับในจะตัดอีกก่อนหมดช่วงทดลอง |
| A-15 | rule ที่มี `endsOn` หรือ `maxOccurrences` ไม่มี occurrence หลังจบ |

## ปฏิทินและตั้งค่า

| # | เกณฑ์ |
|---|---|
| A-16 | ปฏิทินแยกรายการจริง (ทึบ) กับคาดการณ์ (เส้นประ) และด้วยข้อความในรายการด้านล่าง |
| A-17 | ที่ 390px ปฏิทินไม่มีตัวอักษรทับกัน และหน้าไม่ scroll แนวนอน `[e2e]` |
| A-18 | แก้เป้า 10,000 และเรท 33.25 ได้ แถบงานเสริมและยอด ≈ บาทของรายการคาดการณ์เปลี่ยนตาม แต่รายการที่บันทึกแล้วไม่เปลี่ยน `[e2e]` |
| A-19 | ตั้งวันเริ่มรอบ 25 → ป้ายรอบและตัวเลขภาพรวมคำนวณตามรอบใหม่ |
| A-20 | ไม่มีปุ่มเชื่อมธนาคาร ไม่มีช่องรับเลขบัตรเกิน 4 หลัก ไม่มีช่อง CVV/วันหมดอายุ |
| A-21 | ส่งออก CSV เปิดใน Excel/Google Sheets แล้วภาษาไทยไม่เพี้ยน |
