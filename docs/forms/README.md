# Google Forms สำหรับ user test

| ไฟล์ | สร้างอะไร | ฟังก์ชันที่ต้องรัน |
|---|---|---|
| `screener-form.gs` | แบบคัดกรองผู้สมัคร (`docs/12-recruiting-kit.md` §3) | `createScreenerForm` |
| `consent-form.gs` | ใบขออนุญาต (`docs/11-consent-form.md`) | `createConsentForm` |

แต่ละ script สร้าง Google Form พร้อม Google Sheet เก็บคำตอบ ใน Drive ของคนที่กดรัน · วิธีใช้เหมือนกัน (ด้านล่างใช้ใบขออนุญาตเป็นตัวอย่าง) · แบบคัดกรองต้องเติม `slots` เป็นช่วงเวลาที่เปิดจริงด้วย

## ขั้นตอน (~5 นาที)

1. เปิด <https://script.google.com> ด้วยบัญชี Google ที่จะเป็นเจ้าของ Form → **New project**
2. ลบโค้ดตัวอย่าง แล้ววางเนื้อหา `consent-form.gs` ทั้งไฟล์
3. แก้ `CONFIG` ด้านบนให้ครบ: `organizer`, `contact`, `whoSeesData`, `aiTools`, `compensation` (และปรับระยะเวลาเก็บข้อมูลถ้าต้องการ) · ถ้ายังมี `[ … ]` ค้าง script จะหยุดและบอกว่าช่องไหนยังขาด
4. เลือกฟังก์ชัน `createConsentForm` → **Run** → อนุญาตสิทธิ์ Forms / Sheets / Drive (ของบัญชีคุณเอง)
5. เปิด **Execution log** จะเห็น 3 ลิงก์: ลิงก์ส่งให้ผู้ทดสอบ · ลิงก์แก้ไข Form · Sheet คำตอบ
6. เปิดลิงก์แก้ไข แล้วกด Preview ลองตอบ 2 รอบ: เลือก "อนุญาต" ในข้อ 1 (ต้องไปหน้า 2) และ "ไม่อนุญาต" (ต้องไปหน้าขอบคุณแล้วส่ง)

## โครงสร้าง Form

| หน้า | เนื้อหา |
|---|---|
| 1 | คำอธิบาย · สิ่งที่ไม่ต้องทำ · ข้อมูลที่เก็บ/ไม่เก็บ · ระยะเก็บและใครเห็น · สิทธิ์และค่าตอบแทน · **รหัสผู้ทดสอบ** (ต้องเป็น P01–P99) · **ข้อ 1 เข้าร่วม** (บังคับ) |
| 2 | ข้อ 2 อัดหน้าจอ/เสียง · ข้อ 3 เก็บประโยค · ข้อ 4 ยกคำพูด (ตอบทุกข้อ แต่เลือก "ไม่อนุญาต" ได้) · ช่องยืนยันว่าอ่านแล้ว · ชื่อ-นามสกุลแทนลายเซ็น → **ส่ง** |
| 3 | ถ้าข้อ 1 เลือก "ไม่อนุญาต" จะมาหน้านี้ แล้วส่ง (ไม่มีคำถามอื่น) |

การตั้งค่า: ไม่เก็บอีเมล · แก้คำตอบหลังส่งไม่ได้ (ถ้าเปลี่ยนใจให้ติดต่อตามช่องทางใน `contact`) · ข้อความหลังส่งบอกช่องทางขอสำเนา/ถอนความยินยอม

## ข้อควรรู้

- **ทดสอบแล้วแค่ในตัวจำลอง:** ผมยังไม่ได้รันกับ Google จริง (ไม่มีบัญชีใน sandbox) · ตรวจแล้วว่า syntax ถูก รันผ่านทุกขั้นกับ FormApp จำลอง และหยุดจริงเมื่อ CONFIG ยังไม่ครบ · **ให้ทำข้อ 6 ก่อนแจกลิงก์**
- Sheet คำตอบมีทั้ง **ชื่อจริงและรหัส P__** อยู่ด้วยกัน — เก็บ Sheet นี้แยกจากบันทึกการทดสอบ และแชร์ให้เฉพาะคนใน `whoSeesData`
- ใบนี้ใช้กับ user test รอบ 1 (ข้อมูลสมมติ) · pilot รอบ 2 ที่ใช้ข้อมูลจริงและส่งไฟล์วิจัย ต้องมีข้อยินยอมเพิ่ม และควรให้ผู้ตรวจด้าน PDPA อ่านก่อน (T16)
- ถ้าแก้ข้อความใน `docs/11-consent-form.md` ต้องแก้ใน `consent-form.gs` ให้ตรงกันด้วย
