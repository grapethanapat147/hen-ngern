## 5. Gate 1 และเงื่อนไขเปลี่ยนคำตัดสิน

**สมมติฐานที่เสี่ยงที่สุด:** ครูเอาผล "จุดที่ควรทบทวน" + ข้อทบทวนไปใช้จริงในคาบ และยอมแบ่งเวลาเกมมาทบทวน

| | เกณฑ์ (ตั้งเพื่อตัดสินใจ) |
|---|---|
| กลุ่มตัวอย่าง | สัมภาษณ์ครูมัธยมรัฐ 8 คน (≥ 3 คนจากโรงเรียนที่เก็บมือถือ, ≥ 2 คนนอก กทม.) · concierge test 5 คน |
| Metric นำ (ต.ค.) | ครูนัดวันที่จะใช้ข้อทบทวนในคาบแรกๆ ของภาค 2 และ/หรือส่งผลเกมชุดที่สองมาเอง |
| Metric หลัก | จำนวนครูที่เอาข้อทบทวน/สคริปต์ไปใช้ในคาบจริงภายใน 14 วันหลังเปิดภาค 2 (พฤติกรรม ไม่ใช่คำชม) |
| **→ Build prototype** | ≥ 3/5 ใช้จริง **และ** ≥ 2 คนยอม pilot ในห้อง |
| **→ ทำ concierge อีก 1 รอบ** | 2/5 ใช้จริง — ปรับรูปแบบผลวินิจฉัยแล้ววัดใหม่ |
| **→ PARK** | ≤ 1/5 ใช้จริง |
| **→ Pivot เป็น C** | ครูใช้ผลวินิจฉัย แต่ ≥ 4/5 บอกว่าจะไม่เปลี่ยนเครื่องมือเกม |
| **→ ออกแบบโหมดจอเดียว** | ครูจากโรงเรียนที่เก็บมือถือบอกว่าโหมดกลุ่มก็ใช้ไม่ได้ |
| **→ เปลี่ยนกลุ่มเป็นอาจารย์มหาวิทยาลัย** | หาครูมัธยมไม่ถึง 8 คนภายใน 25 ต.ค. |
| **→ DROP** | ครูส่วนใหญ่บอกว่าผลรายข้อจาก Kahoot/Wayground พอแล้ว และไม่มีใครใช้ข้อทบทวน |

**Guardrail ระหว่าง concierge:** ไม่รับข้อมูลที่ระบุตัวนักเรียน · ถ้ามีข้อทบทวนผิดข้อเท็จจริงส่งถึงครู ≥ 1 ครั้ง → หยุดแก้กระบวนการตรวจก่อน
