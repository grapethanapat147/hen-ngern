## 0) คำสั่งสั้นสำหรับ Claude Code

สร้างเว็บแอปภาษาไทยชื่อ **รู้เงิน** ให้คนจดรายรับ รายจ่าย และบิลซ้ำในหน้าเดียว โดยไม่เชื่อมธนาคาร

เป้าหมายรอบนี้ไม่ใช่แอปบัญชีเต็มใบ และไม่ใช่แค่ clone Billbau  
ต้องชนะ Billbau ที่: มีฝั่งรายรับ, มีรายจ่ายครั้งเดียว, มีเป้าเงินเสริม, จดด้วยประโยคได้ใน 10 วินาที, มีวันสิ้นสุด / จบหลัง N ครั้ง

ทำเป็นเว็บ responsive (มือถือก่อน เดสก์ท็อปตาม)  
ข้อมูลเก็บ `localStorage`  
ห้ามล็อกอิน ห้ามขอสิทธิ์แบงก์ ห้ามเรียก LLM API ใน v0  
อย่าประดิษฐ์ตัวเลขรายได้จริงในข้อมูลตัวอย่าง ให้ติดป้ายว่าเป็นตัวอย่าง

ถ้าต้องเลือก เลือกความชัดของตัวเลขและความเร็วในการจด มากกว่าแอนิเมชันหรือแดชบอร์ดแน่น

## 1) สินค้าและปัญหา

### สินค้าคืออะไร
สมุดเงินส่วนบุคคลสำหรับคนไทยที่จ่ายบิลซ้ำหลายใบ (มักเป็นซอฟต์แวร์/AI ต่างสกุล) และมีรายรับไม่ก้อนเดียว

ประโยคบนสินค้า: **เห็นเงินเข้า เงินออก และวันตัดในก้อนเดียว**

### ปัญหาที่ต้องแก้
1. จดแต่บิลซ้ำแล้วช็อกตอนเห็นยอดจ่าย โดยไม่มีตัวเทียบว่ารายรับเดือนนี้เท่าไร
2. แอปจดทั่วไปบังคับเปิดฟอร์มยาว เลยไม่จดรายการจิบ
3. ทดลองใช้ฟรีกลายเป็นบิลโดยไม่ทันยกเลิก
4. วันตัดหลายใบชนกัน แต่ไม่มีปฏิทินที่โชว์ทั้งเงินเข้าและเงินออก
5. คนมีเป้าเงินเสริม แต่แอปเงินทั่วไปไม่ผูกเป้านี้กับสมุด

### ไม่ใช่ปัญหาของ v0
ปิดงบภาษี, แชร์กระเป๋าครอบครัว, เชื่อม Open Banking, OCR สลิป, ลงทุน, ระบบผ่อนบ้านเต็มใบ, มอนิไทซ์

## 2) ผู้ใช้และงานที่ต้องจบ

ผู้ใช้หลัก: คนทำงานไทย อายุประมาณ 22–40 ใช้มือถือเป็นหลัก มีบัตร/วอลเล็ตหลายใบ จ่ายค่าโมเดลหรือ SaaS เป็น USD รายรับเป็นบาทจากงานประจำ + งานพาร์ตไทม์ + คิวไม่คงที่  
ไม่ยอมเชื่อมบัญชีธนาคาร

### Jobs to be done (เรียงตามความสำคัญ)
1. รู้ว่าเดือนนี้เข้าเท่าไร จ่ายเท่าไร เหลือประมาณเท่าไร — ใน 5 วินาทีหลังเปิดแอป
2. จดรายการใหม่ด้วยประโยค โดยไม่ต้องหาฟอร์ม
3. เห็นบิลหรือทดลองใช้ที่จะถึงใน 7 วัน
4. รู้ว่างานเสริมเดือนนี้ขาดจากเป้าอีกเท่าไร
5. เปิดปฏิทินแล้วรู้วันไหนกระเป๋าตึง
6. แก้ราคา / วันจบ / รอบของบิลซ้ำได้โดยไม่ทำลายประวัติความเข้าใจ (v0 เก็บค่าปัจจุบันก่อน ประวัติราคาเต็มเป็น v0.1)

เกณฑ์ผ่านของงานข้อ 2: จากโฟกัสช่องพิมพ์ถึงบันทึกสำเร็จ ไม่เกิน 10 วินาทีสำหรับเคสง่าย

## 3) หลัก UX ที่ห้ามผิด

1. **Answer first.** หน้าแรกต้องตอบข้อ 1 ก่อนเลื่อน
2. **ร่างก่อนบันทึก.** ประโยคที่แปลงได้ต้องโชว์ร่างให้แก้ ห้ามเขียนลงสมุดเงียบ ๆ
3. **ทุกยอดต่างสกุลมีบาทคู่.** แสดงต้นทาง เช่น `US$20 ≈ ฿665` ไม่ซ่อนสูตร
4. **ตัวอย่างไม่ปลอมเป็นของจริง.** ข้อมูลซีดติดคำว่าตัวอย่าง
5. **ไม่เชื่อมแบงก์คือฟีเจอร์.** เขียนบนหน้าแรกและหน้าตั้งค่า ไม่ใช่เชิงขอโทษ
6. **มือถือก่อน.** ช่องพิมพ์และปุ่มบันทึกใช้นิ้วโป้งถึงได้
7. **ความเห็นจากสมุดเท่านั้น.** กล่อง insight คิดจากรายการที่มี ห้ามเดารายได้
8. **อย่าทำเป็นแชทบอท.** AI ใน v0 คือช่องแปลงประโยค + กล่องสรุป ไม่มีบับเบิลคุยยาว

## 5) Visual system

ไม่คัดลอกพาเลตม่วงพาสเทลของ Billbau แบบหนึ่งต่อหนึ่ง  
รู้เงินใช้โทนกระดาษอุ่น + เขียวน้ำทะเล สำหรับของที่ต้องเชื่อถือได้

| Token | ค่า | ใช้เมื่อ |
|---|---|---|
| Paper | `#F7F2EA` | พื้นหลัง |
| Card | `#FFFCF7` | การ์ด |
| Ink | `#161410` | ตัวอักษรหลัก |
| Muted | `#6B6458` | คำอธิบาย |
| Line | `#E6DFD2` | เส้น |
| Teal | `#0B6B66` | ปุ่มหลัก, รายรับ, ความคืบหน้าเป้า |
| Amber | `#D99412` | เตือนใกล้ตัด, ยอดจ่าย |
| Coral | `#C24B3A` | ทดลองใกล้หมด, ลบ, เดือนติดลบ |
| Sage | `#3D6B4F` | ป้ายรายรับ |
| Navy | `#243044` | การ์ดสรุปเข้ม |

ตัวอักษร: `Be Vietnam Pro` + `Noto Sans Thai`  
มุมการ์ด 16–20px  
ปุ่มหลักเป็นเม็ดยาว ไม่เป็นก้อนเหลี่ยมใหญ่  
โลโก้: ช่องเหลี่ยมมนมีคำว่า **รู้** สีขาวบนพื้น teal

ความหนาแน่น: หน้าเดสก์ท็อปกว้างสุด ~1180px  
มือถือ padding 16px หลีกเลี่ยงตารางหลายคอลัมน์

แยกสีฝั่งเงิน:
- รายรับ = เขียว / +฿
- รายจ่าย = หมึกเข้ม / −฿
- ทดลองใช้ = พื้นปะการังอ่อน + นับวันเหลือ
- วันจ่ายหนัก = พื้นเหลืองอ่อน

อย่าใช้กราฟวงกลมเป็นพระเอกของหน้าแรก ใช้ตัวเลขใหญ่ 4 ช่องก่อน

## 6) โครงสร้างหน้า

### 6.1 แถบพิมพ์ประโยค (ทุกหน้า)

ตำแหน่ง: ใต้หัวแอป เหนือแท็บ  
องค์ประกอบ:
- ป้าย: `พิมพ์เป็นประโยค แล้วตรวจร่างก่อนบันทึก`
- ช่องเดียว
- ปุ่ม `แปลง`

Placeholder สลับได้ 3 ชุด:
1. `ได้ค่างาน Mercor 4,500`
2. `จ่าย Netflix 419 ทุกเดือนวันที่ 5 บัตรกสิกร`
3. `ทดลอง Perplexity 20 ดอลลาร์ ถึง 2 ต.ค.`

สถานะ:
- ว่าง: ปุ่มแปลงจาง
- แปลงได้: การ์ดร่างโชว์ชนิด ชื่อ ยอด สกุล บาทโดยประมาณ รอบ หมวด บัญชี
- แปลงไม่ได้: `ใส่ยอดเป็นตัวเลข เช่น จ่ายกาแฟ 65`
- ผู้ใช้กด `เปิดฟอร์มยืนยัน` หรือ `บันทึกเลย` ถ้าครบชื่อ+ยอด+วันที่

กติกา parser v0 (ไม่เรียกโมเดล):
- คำขึ้นต้น `ได้ / รับ / เงินเดือน / โอนเข้า` = รายรับ
- คำขึ้นต้น `จ่าย / ค่า / ทดลอง` = รายจ่าย
- `$ USD ดอลลาร์` = USD, นอกนั้น THB
- `ทุกเดือน รายเดือน เงินเดือน` = month
- `ทุกปี รายปี` = year
- `ทุกสัปดาห์` = week
- นอกนั้น = once
- `วันที่ 5` ใส่วันในเดือนปัจจุบัน
- แมปบัญชีจากคำว่า กสิกร/KBank, SCB/ไทยพาณิชย์, TrueMoney/วอลเล็ต นอกนั้นเงินสด
- แมปหมวดจากพจนานุกรมบริการ (Netflix, Claude, ChatGPT, Mercor ฯลฯ)

ห้ามบันทึกถ้ายอดเป็น 0 หรือไม่มีชื่อ

### 6.2 หน้าภาพรวม

เหนือพับ เรียงจากบนลงล่าง:

1. **4 ตัวเลขใหญ่**
   - คงเหลือโดยประมาณ = รายรับเดือนนี้ − รายจ่ายเดือนนี้
   - รายรับเดือนนี้
   - รายจ่ายเดือนนี้
   - งานเสริม / เป้า (เช่น `฿12,500 / เป้า ฿10,000`)
2. **แถวบัญชี** การ์ดแนวนอนเลื่อนได้  
   ชื่อบัญชี, 4 ตัวท้าย, จำนวนรายการเดือนนี้, ยอดจ่ายเดือนนี้ของบัญชีนั้น
3. **ใกล้ตัดใน 7 วัน** รายการ 5–7 แถวแรก  
   ถ้ารายการเป็นช่วงทดลอง แสดง `เหลือ N วัน` และยอดที่จะโดนถ้าไม่ยกเลิก
4. **ความเห็นจากสมุด** รายการข้อความ 4–6 ข้อ คิดจากข้อมูลจริงในเดือนที่เปิดอยู่

ความเห็นที่อนุญาต:
- เข้า / จ่าย / คงเหลือ
- งานเสริมเทียบเป้า ขาดอีกเท่าไร
- สัดส่วนหมวดงาน/ซอฟต์แวร์ต่อรายจ่ายเดือนนั้น
- วันที่จ่ายหนักสุด
- บัญชีที่โดนหนักสุด
- ทดลองใช้ที่ยังไม่หมด พร้อมยอดประมาณ
- ถ้าจ่าย > เข้า: เตือนให้ตรวจบิลซ้ำ ห้ามพูดว่า “คุณใช้เกิน”

คลิกแถวรายการ = เปิดฟอร์มแก้  
คลิกการ์ดบัญชี = กรองหน้าเงินเข้า-ออกของบัญชีนั้น (ถ้ายังไม่ทำกรองใน v0 ให้เปิดชีตแก้บัญชี)

### 6.3 หน้าเงินเข้า-ออก

รายการทุกอีเวนต์ในเดือนที่เลือก เรียงวัน  
กรองชิป: ทั้งหมด / รายรับ / รายจ่าย / ครั้งเดียว / ซ้ำ  
ค้นหาชื่อ  
แต่ละแถว: กล่องวัน, ชื่อ, หมวด, บัญชี, สกุลต้นทางถ้าไม่ใช่บาท, ยอดบาท

ค่าเริ่มเดือน = เดือนปัจจุบันของเครื่องผู้ใช้ ไม่ล็อกกันยายน 2026

### 6.4 หน้ารายการซ้ำ

ตารางหรือการ์ดรายการที่ `mode != once`  
คอลัมน์ขั้นต่ำ: ฝั่ง, ชื่อ, รอบ, ราคาต้นทาง, บาท, บัญชี, วันในรอบ, วันจบหรือจำนวนครั้ง, สถานะทดลอง

ปุ่ม `+ บิลซ้ำ` เปิดฟอร์มโหมด month เป็นค่าเริ่ม

ต้องรองรับของที่คนในโพสต์ Billbau ขอ:
- วันสิ้นสุด
- จบหลัง N ครั้ง
- รายการครั้งเดียว (อยู่ในหน้าเงินเข้า-ออก ไม่ปนตารางนี้)

### 6.5 หน้าปฏิทิน

ปฏิทินเดือน  
เซลล์แสดงจุดสั้น 2–3 รายการ เช่น `+เงินเดือน` `−Netflix`  
วันที่มีทั้งเข้าและออกใช้สองสี  
แผงขวาหรือใต้ปฏิทิน (มือถือ): รายการของวันที่เลือก  
ค่าเริ่ม = วันนี้

ห้ามทำเป็นปฏิทินตารางที่อ่านไม่ออกบนจอ 375px — ถ้าแคบให้เหลือตัวเลขวัน + จุดสี แล้วโชว์รายการด้านล่าง

### 6.6 หน้าเป้าและตั้งค่า

- เป้าเงินเสริมรายเดือน แก้ได้ ค่าเริ่ม `10000`
- แถบความคืบหน้างานเสริมเดือนนี้ / เป้า
- เรท USD→THB แก้ได้ ค่าเริ่ม `33.25` พร้อมประโยค: `เรทนี้ตั้งเอง ไม่ใช่เรทเข้าบัญชี`
- ส่งออก JSON
- โหลดข้อมูลตัวอย่าง (มี confirm)
- ล้างข้อมูลในเครื่อง
- ข้อความนโยบาย: ไม่เชื่อมธนาคาร ไม่เก็บเลขบัตรเต็ม ข้อมูลไม่ขึ้นคลาวด์ใน v0

## 7) ฟอร์มรายการ

เปิดจากปุ่ม `+ รายการ`, จากร่างประโยค, หรือจากแถวที่มีอยู่

ฟิลด์และกติกา:

| ฟิลด์ | บังคับ | หมายเหตุ |
|---|---|---|
| ชนิด | ใช่ | รายรับ / รายจ่าย |
| รูปแบบ | ใช่ | ครั้งเดียว / รายสัปดาห์ / รายเดือน / รายปี |
| ชื่อ | ใช่ | |
| ยอด | ใช่ | ตัวเลข > 0 |
| สกุล | ใช่ | THB / USD / EUR |
| หมวด | ใช่ | ชุดตามชนิด |
| บัญชี | ใช่ | |
| วันที่ | ใช่ | วันตัดหรือวันรับครั้งแรก |
| วันสิ้นสุด | ไม่ | ซ่อนถ้าครั้งเดียว |
| จบหลังกี่ครั้ง | ไม่ | ว่าง = ไม่จำกัด, ซ่อนถ้าครั้งเดียว |
| ทดลองใช้ถึง | ไม่ | โชว์ชัดเมื่อเป็นรายจ่ายซ้ำ |
| บันทึก | ไม่ | |

หมวดรายรับ: เงินเดือน, งานเสริม, ครอบครัว, อื่น ๆ  
หมวดรายจ่าย: งาน/ซอฟต์แวร์, บันเทิง, สุขภาพ, อาหาร, เดินทาง, บ้าน, คลาวด์, เพลง, อื่น ๆ

มือถือใช้ bottom sheet ไม่ใช้โมดัลกลางจอที่ถูกคีย์บอร์ดบัง  
เดสก์ท็อปใช้แผงกว้างไม่เกิน 560px

ปุ่ม: บันทึก, ยกเลิก, ลบ (โชว์ตอนแก้เท่านั้น + confirm)

หลังบันทึก: ปิดชีต, กลับหน้าเดิม, โฟกัสรายการที่เพิ่งบันทึกถ้ามองเห็น

## 9) Copy ภาษาไทยที่ล็อกแล้ว

ใช้คำเหล่านี้ ไม่สุ่มคำใหม่:

- สินค้า: รู้เงิน
- แท็บ: ภาพรวม, เงินเข้า-ออก, รายการซ้ำ, ปฏิทิน, เป้า
- ฝั่ง: รายรับ, รายจ่าย
- ตัวเลขหน้าแรก: คงเหลือโดยประมาณ, รายรับเดือนนี้, รายจ่ายเดือนนี้, งานเสริม
- ปุ่ม: แปลง, บันทึก, ยกเลิก, ลบ, ส่งออก JSON, โหลดข้อมูลตัวอย่าง
- นโยบายสั้น: `ใช้ฟรีในเครื่องนี้ · ไม่เชื่อมบัญชีธนาคาร`
- ทดลอง: `ยกเลิกก่อนหมด = ไม่โดนหัก`
- เรท: `เรทนี้ตั้งเอง ไม่ใช่เรทเข้าบัญชี`
- ข้อมูลซีด: `ตัวอย่าง ไม่ใช่ยอดจริง`

น้ำเสียง: ชัด สั้น เป็นคนพูด ไม่ใช่แบงก์ ไม่ใช่โค้ชชีวิต  
ห้ามคำว่า “ปฏิวัติการเงิน”, “AI อัจฉริยะ”, “จัดการความมั่งคั่ง”

## 10) โมเดลข้อมูลที่ UI ต้องรองรับ

```ts
type Kind = "income" | "expense"
type Mode = "once" | "week" | "month" | "year"
type Currency = "THB" | "USD" | "EUR"

interface Account {
  id: string
  name: string
  type: "card" | "wallet" | "cash" | "promptpay"
  last4: string
}

interface Item {
  id: string
  kind: Kind
  mode: Mode
  name: string
  amount: number
  currency: Currency
  category: string
  accountId: string
  date: string        // YYYY-MM-DD วันแรก
  endDate?: string
  occurrences?: number
  trialEnds?: string
  note?: string
}

interface AppState {
  fxUsd: number       // default 33.25
  fxEur: number       // default 36.4
  goalSide: number    // default 10000
  accounts: Account[]
  items: Item[]
}
```

กติกาคำนวณที่ UI ต้องแสดงให้ตรง:
- บาท = `amount * fx` ของสกุลนั้น
- รายการซ้ำขยายเป็นอีเวนต์ในเดือนที่เปิด
- ช่วงทดลองของรายจ่ายซ้ำ: ยังไม่นับเป็นยอดจ่ายจนกว่าจะถึง `trialEnds` จากนั้นแสดงยอดที่จะเริ่มหัก
- `endDate` และ `occurrences` ตัดอีเวนต์หลังจบ
- งานเสริม = รายรับที่หมวดเป็น `งานเสริม` ในเดือนนั้น
- คงเหลือโดยประมาณไม่ใช่ยอดบัญชีธนาคาร

คีย์เก็บข้อมูล: `roongern.v0`

## 11) ข้อมูลตัวอย่างที่อนุญาต

ใช้ชุดสาธิต “คนทำงานโปรดักต์ที่มีบิลซอฟต์แวร์ต่างสกุล + งานเสริม”  
ติดโน้ตตัวอย่างทุกบรรทัดที่เป็นเงินเดือนหรือคิวงาน

รายรับตัวอย่าง:
- เงินเดือนงานประจำ 45,000 THB รายเดือน วันที่ 28 — ตัวอย่าง ไม่ใช่ยอดจริง
- งานพาร์ตไทม์ 8,000 THB รายเดือน วันที่ 25
- งานเสริมครั้งเดียว 4,500 THB วันที่ 18

รายจ่ายซ้ำยึดโครงบิลที่คนกลุ่ม Claude TH คุ้น (Netflix, YouTube, Claude, ChatGPT, Notion, Google One, Fitness First, Adobe, GitHub Copilot, Spotify, Perplexity ช่วงทดลอง)  
บวกค่าเช่าและรายการจิบอาหาร/เดินทาง เพื่อไม่ให้สมุดมีแต่สมาชิก

ห้ามใส่ชื่อ-นามสกุลเจ้าของโปรเจกต์ใน UI  
ห้ามเขียนว่ายอดเหล่านี้เป็นรายได้จริง

## 13) เกณฑ์รับงาน (ยอมรับจาก UX)

งานผ่านเมื่อทำได้ครบข้อนี้บนมือถือกว้าง 390px และเดสก์ท็อป 1280px:

1. เปิดแอปครั้งแรกเห็น 4 ตัวเลข + ช่องพิมพ์ โดยไม่ต้องสมัคร
2. พิมพ์ `ได้ค่างาน 4500` แล้วบันทึก ไปโชว์ฝั่งรายรับ
3. พิมพ์ `จ่าย Netflix 419 ทุกเดือนวันที่ 5 บัตรกสิกร` แล้วไปโชว์ในรายการซ้ำและปฏิทิน
4. รายการ USD โชว์ทั้งต้นทางและบาท
5. การ์ดทดลองใช้บอกวันเหลือและยอดที่จะโดน
6. หน้าเป้าแก้ตัวเลข 10,000 และเรท 33.25 ได้ แถบความคืบหน้าขยับตาม
7. รีเฟรชแล้วยังอยู่
8. ไม่มีปุ่มเชื่อมธนาคาร ไม่มีช่องเลขบัตรเกิน 4 ตัวท้าย
9. คำบนหน้าใช้ชุด copy ที่ล็อกในข้อ 9
10. Insight ไม่มีตัวเลขที่ไม่มีในสมุด
