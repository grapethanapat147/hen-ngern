# Brief: เว็บเกมควิซสดในห้องเรียนสำหรับครูมัธยมไทย

ตรวจ ณ 26 กันยายน 2026  
บทบาท: นักวิจัยตลาด edtech ที่ใช้ข้อมูล real-time  
จุดต่างที่ต้องการทดสอบ: หลังเกมบอกได้ว่านักเรียนเข้าใจผิดเรื่องอะไร (ไม่ใช่แค่ % ถูก) + สร้างรอบซ่อมในคาบ + หลักฐานผลลัพธ์ผู้เรียนสำหรับ วPA

ป้ายที่ใช้ในเอกสารนี้

- **Fact** — มีแหล่งปฐมภูมิหรือหน้าทางการ + วันที่
- **Calculation** — คำนวณจาก Fact ที่อ้างแล้ว
- **Assumption** — สมมติฐานที่ยังไม่พิสูจน์
- **Inference** — สรุปจาก Fact แต่ยังไม่ใช่ข้อเท็จจริงตรง
- **Recommendation** — ข้อเสนอการทดลอง ไม่ใช่แผนเปิดตัว
- **Unknown** — ค้นแล้วไม่เจอ ห้ามเดาตัวเลข

งานนี้เป็น **mass AI product** สำหรับครูมัธยมไทย ไม่ใช่ client AI solution

- ผู้ใช้ / ผู้ซื้อ: ครูที่จ่ายเองหรือขอโรงเรียนซื้อ
- JTBD: ในคาบนี้รู้ว่าเด็กเข้าใจผิดเรื่องอะไร ซ่อมได้ทันที และเหลือหลักฐานผลลัพธ์ผู้เรียนที่ส่ง วPA ได้
- Baseline ปัจจุบัน: Kahoot / Wayground / Wordwall / Baamboozle + Excel + เขียนรายงาน PA เอง
- Desired outcome: misconception + รอบซ่อมในคาบ + ไฟล์หลักฐานด้านที่ 2

ห้ามใช้เอกสารนี้เป็นหลักฐานว่ามีผู้ใช้ รายได้ ราคาขาย หรือผลลัพธ์ของสินค้าที่ยังไม่ได้สร้าง

## 2. บริบทครูไทย

### 2.1 ขนาดห้องเรียนมัธยมรัฐ

**Fact.** รายงานประจำปี สพฐ. 2567 ข้อมูล ณ 10 พฤศจิกายน 2567: อัตรานักเรียนต่อห้อง

- มัธยมศึกษาตอนต้นรวม 1,667,458 คน / 60,656 ห้อง = 1 : 27
- ม.1 = 1 : 29
- ม.2 = 1 : 27
- ม.3 = 1 : 27
- ม.4 = 1 : 31
- ม.5 = 1 : 30
- ม.6 = 1 : 30

แหล่ง: https://eva.obec.go.th/wp-content/uploads/2025/02/รายงานประจำปี-2567.pdf (ชื่อไฟล์ต้นทางบนเซิร์ฟเวอร์ สพฐ.)  
เผยแพร่ในชุดรายงานปี 2567 เมื่อ ก.พ. 2568

**Fact.** มาตรฐานอาคารมัธยมฉบับเก่าของ สพฐ. คิดแผนชั้นเรียนที่ห้องละ 40 คน — เป็นเกณฑ์ออกแบบ ไม่ใช่ค่าเฉลี่ยจริงปี 2567  
แหล่ง: https://secondary.obec.go.th/newweb/wp-content/uploads/2017/12/standradmuttayom52.pdf

**Calculation.** ค่าเฉลี่ย ม.ต้นประมาณ 27 คน อยู่ภายในโควต้าฟรี Kahoot ครู K-12 (40), Wayground (100) และ Blooket (60) ห้องที่แน่นตามมาตรฐาน 40 พอดีเพดานฟรี Kahoot ห้องพิเศษ / รวมห้อง / กิจกรรมทั้งระดับที่เกิน 40 จะชนเพดานฟรี Kahoot

**Unknown.** ไม่ใช้ค่าเฉลี่ยนี้แทนการกระจายรายโรงเรียน โรงเรียนใหญ่ในเมืองอาจสูงกว่า 40 ต่อห้อง แต่รายงาน สพฐ. ที่เปิดได้ให้เป็นค่าเฉลี่ยทั้งสังกัด

## 4. ช่องว่างตลาด 3 ข้อ และหลักฐานที่ค้านไอเดีย

ช่องว่างด้านล่างเป็นโอกาสที่ยังไม่พิสูจน์ ไม่ใช่ส่วนแบ่งตลาด หรือหลักฐานว่าสินค้าจะชนะ

### ช่องว่าง 1 — วินิจฉัยความเข้าใจผิดเป็นภาษาไทย ระดับมโนทัศน์ ไม่ใช่แค่ % ข้อ

**Fact.** Kahoot รายงานข้อยาก + ตัวเลือกที่ถูกเลือก Wayground อธิบายคำตอบและจัดกลุ่มย่อยบนแผนโรงเรียน ไม่มีเจ้าที่เปิดสเปกว่าแมปตัวลวง → มโนทัศน์หลักสูตรไทย แล้วพูดเป็นประโยคครูใช้ได้ทันที

**Inference.** ช่องว่างจริงถ้าโมเดลทำภาษาไทย + หลักสูตรได้ และครูแก้ข้อที่เจนได้ใน 2 นาที

### ช่องว่าง 2 — รอบซ่อมในคาบเดียวกัน ไม่ใช่การบ้านคนละวัน

**Fact.** Kahoot มีปุ่มสร้างเกมใหม่จากข้อยากหลังจบ ไม่เจอเจ้าที่ล็อกเวลาคาบ 50 นาทีแล้วปล่อยรอบซ่อมอัตโนมัติเฉพาะข้อ / คนที่ผิด

**Assumption ที่ต้องทดสอบ:** ครูยอมตัดเวลาเกมรอบแรกเพื่อซ่อม หรือยังอยากได้ลีดเดอร์บอร์ดเต็มคาบ

### ช่องว่าง 3 — แพ็กหลักฐานด้านที่ 2 ของ วPA

**Fact.** ก.ค.ศ. ต้องการไฟล์ผลงานผู้เรียนหลังสอน เชื่อมประเด็นท้าทาย ไม่ใช่คะแนนเกม ตลาดไฟล์ PA 89 บาทบอกว่าครูจ่ายเพื่อเอกสาร

**Inference.** ถ้าสินค้าส่งออก PDF / ภาพก่อน-หลังรายคนที่เข้า DPA ได้ จะชน pain ที่เห็นจริงกว่า “เกมสนุกกว่า Kahoot”

### หลักฐานที่ค้านไอเดียนี้

1. **นโยบายมือถือ** — กทม. 437 โรงห้ามใช้เครื่องในเวลาเรียนตั้งแต่ พ.ค. 2569 สพฐ. ให้โรงเรียนห้ามได้ เกมที่บังคับ 1 คน 1 เครื่องพังในบริบทนี้ถ้าไม่มีโหมดจอเดียว / ทีม / กระดาษ
2. **คู่แข่งฟรีครอบคลุมห้องเฉลี่ยแล้ว** — ม.ต้นเฉลี่ย 27 คน/ห้อง Kahoot ครูฟรี 40, Wayground ฟรี 100, Blooket ฟรี 60 จุดต่างต้องแรงกว่า “เล่นฟรีทั้งห้อง”
3. **วPA ไม่รับ % ควิซเป็นผลลัพธ์ผู้เรียน** — คู่มือ ก.ค.ศ. ย้ำชิ้นงาน / ร่องรอยหลังสอน ถ้าสินค้าส่งแค่ dashboard เกม จะไม่แก้ pain เอกสารที่ครูจ่ายเงินอยู่แล้ว
4. **Kahoot ทำรีไซเคิลข้อยากอยู่แล้ว** — ปุ่ม Create จากข้อที่ถูกน้อยกว่า 35% ลดความใหม่ของ “รอบซ่อม” ถ้าซ่อม = เล่นข้อเดิมซ้ำ
5. **สัญญาณโซเชียลของจุดต่างยังบาง** — 12 เดือนที่เห็นคือขายไฟล์ PA และคู่มือเก็บคะแนน ไม่ใช่คำร้องว่า “ขอเครื่องมือบอกว่าเข้าใจผิดเรื่องอะไร”

| Owner | ผู้ทำ discovery |
| Dependency | ชุดข้อสอบจริง 1 บท + ครูที่ยอมให้สังเกตคาบ + นโยบายมือถือของโรงเรียนนั้น |

### การประเมิน AI ถ้าทำต่อ

- Evaluation set: ข้อหลักสูตร ม.ต้น 3 วิชา × ตัวลวงที่ครูติดป้ายแล้ว
- Human review ก่อนปล่อยให้นักเรียนเห็น
- Failure handling: ส่งเฉพาะ % ถูก ไม่ส่งประโยควินิจฉัยถ้าโมเดลไม่ผ่านเกณฑ์
- Privacy: ไม่เก็บรายชื่อนักเรียนไปโมเดลภายนอกโดยไม่ขอ
- ต้นทุนต่อคาบต้องต่ำกว่าที่ครูยอมจ่ายเอง — ยัง **Unknown** ว่าเท่าไร ห้ามเดาราคา
