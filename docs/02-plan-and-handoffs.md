## 4. Handoff → Grok (follow-up รอบ 2)

```
บทบาท: นักวิจัยตลาด edtech ที่ใช้ข้อมูล real-time
บริบท: ต่อจาก brief "เว็บเกมควิซสดในห้องเรียนสำหรับครูมัธยมไทย" ที่คุณทำเมื่อ 26 ก.ย. 2026

ขอตรวจ 5 เรื่องที่ยังเปิด:
1. หน้า PA ของ ก.ค.ศ. (otepc.go.th/th/inform-services/pa-2) อ้าง "ว 12/2569" — หนังสือนี้คืออะไร เปลี่ยนเกณฑ์หรือหลักฐานด้านที่ 2 จาก ว 9/2564 หรือไม่ อ้างเอกสาร ก.ค.ศ. โดยตรง
2. นอก กทม. มีข้อมูลระดับจังหวัด/สพท./โรงเรียนเรื่องการเก็บมือถือในคาบไหม (ยกตัวอย่างประกาศจริงพร้อมลิงก์ ไม่ต้องประมาณสัดส่วนถ้าไม่มีข้อมูล)
3. แก้ข้อสรุปเดิม: นโยบาย กทม. "Phone Off, Learning On" ยังสนับสนุนการใช้อุปกรณ์เพื่อการเรียนรู้ภายใต้ครู ช่วยหาแนวปฏิบัติจริงว่าครูขอใช้เครื่องในคาบอย่างไร
4. Vonder Go ปี 2026 ยังให้บริการครูอยู่ไหม ราคาและเพดานผู้เล่น
5. Kahoot สำหรับครู K-12: ดูรายงานรายข้อ/การกระจายคำตอบได้ในแผนฟรีไหม และ download ได้แผนไหน อ้างหน้า Help

กติกา: ทุก fact มี URL + วันที่ · ใช้แหล่งทางการก่อน · แยก Fact / Inference / Unknown · ไม่เจอให้บอกว่าไม่เจอ
ปิดท้ายด้วย Handoff Block สั้นๆ
```
