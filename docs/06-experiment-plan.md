# 06 — Experiment Plan: พิสูจน์ก่อนเพิ่ม AI

ตัวเลขเป้าหมายทั้งหมดในเอกสารนี้ **ตั้งไว้ล่วงหน้าเป็นเกณฑ์ทดลอง** ไม่ใช่ผลวิจัยหรือ benchmark ตลาด

## สมมติฐาน

| # | สมมติฐาน | วัดอย่างไร | ผ่านเมื่อ |
|---|---|---|---|
| H1 | คนจดรายการแรกได้เองด้วยประโยคเดียวโดยไม่ต้องสอน | สังเกตใน user test | ≥ 6/8 คน |
| H2 | คนแยก "เงินจริง" กับ "คาดการณ์" ได้จากหน้าแรก | ถามให้อธิบายตัวเลข 4 ช่อง | ≥ 6/8 คน อธิบายถูก |
| H3 | ตัวเลขไม่หลอกผู้ใช้ | ให้ทำ transfer + จ่ายบัตร + refund | 0 เคสที่ยอดนับซ้ำแล้วผู้ใช้ไม่รู้ตัว |
| H4 | การจดด้วยประโยคเร็วพอ | จับเวลาจากโฟกัสถึงบันทึก | median ≤ 10 วินาที (เคสง่าย) |
| H5 | คนอยากใช้ต่อกับข้อมูลจริง | ถามท้าย session + ดู pilot | ≥ 3/8 ขอใช้ต่อ · pilot กลับมาจด ≥ 4 วัน/สัปดาห์ ≥ 50% ของคน |

## รอบ 1 — User test (7–10 วัน หลัง P7)

- **ผู้เข้าร่วม 8 คน:** คนทำงานมีบิลซ้ำ 4 คน · มีงานเสริม/ฟรีแลนซ์ 4 คน
- ใช้ **ข้อมูลตัวอย่างหรือข้อมูลสมมติ** เท่านั้น ห้ามให้ใส่ข้อมูลการเงินจริงระหว่างทดสอบ
- เริ่มด้วยสัมภาษณ์ 10 นาที: ตอนนี้จดเงินยังไง, เคยเลิกจดเพราะอะไร, ใช้เหมียวจด/Money Lover/Excel ไหม (ปิดข้อมูลอ่อนไหว)
- งาน 5 ข้อ:
  1. จดรายรับจากงาน 1 รายการ
  2. เพิ่มบิลซ้ำ 1 ตัวที่จ่ายเป็น USD
  3. จ่ายยอดบัตรเครดิต แล้วตรวจว่าจ่ายจริงเปลี่ยนไหม
  4. บอกว่ารอบนี้จะโดนตัดอีกเท่าไร และต่างจากจ่ายจริงยังไง
  5. หาว่าวันไหนเงินออกเยอะที่สุด
- เก็บประโยคที่ผู้ใช้พิมพ์ (ขออนุญาตก่อน) → ใช้เป็น eval set ของ parser/LLM ใน v0.1

## รอบ 2 — Pilot (2–4 สัปดาห์)

- ผู้สมัครใจใช้กับข้อมูลจริงบนเครื่องตัวเอง (ข้อมูลไม่ออกจากเครื่องใน v0) · ใบยินยอมและแบบฟอร์มรายสัปดาห์: `13-pilot-consent-form.md`
- ไม่มี analytics ใน v0 → เก็บผลด้วย **แบบฟอร์มรายสัปดาห์ + ให้ผู้ใช้กด `ตั้งค่า → ส่งออกสำหรับงานวิจัย` แล้วส่งไฟล์มา** (ถ้ายินยอม) · ไฟล์ไม่มีชื่อรายการ หมายเหตุ ยอดเงิน ชื่อบัญชี 4 ตัวท้าย และเวลา (ดู `src/domain/research.ts`)
- ตัวชี้วัด: จำนวนวันที่จด/สัปดาห์ (`summary.activeDaysByWeek`) · จำนวนรายการที่ยืนยัน (`confirmedCount`) · สัดส่วนร่างที่ต้องแก้ (`1 − sentenceUncorrectedCount / fromSentenceCount`, แยกรายช่องใน `correctionsByField`) · จำนวนบิลที่กด "จ่ายแล้ว" (`paidOccurrenceCount`) · ปัญหายอดผิดที่ผู้ใช้รายงาน (จากแบบฟอร์ม)

## North star ชั่วคราว

จำนวนผู้ใช้ต่อสัปดาห์ที่มีรายการจริงที่ยืนยันแล้ว และกลับมาอัปเดตรายการที่จะถึง
**Guardrail:** 0 รายงานยอดผิดจากการนับซ้ำที่ไม่ได้แก้
