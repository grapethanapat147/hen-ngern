# Prompt 01 — Phase A: Game engine ไม่มี AI (P1–P4)

ใช้เมื่อ: P0 เสร็จแล้ว **และ** ผ่านเงื่อนไขอย่างน้อยหนึ่งข้อด้านล่าง ลบข้อที่ไม่ใช่ออกก่อนวาง

---

เงื่อนไขที่ผมเลือก (อ้างอิง `docs/00-decision-review.md`):
- Gate 1 ผ่านแล้ว และบันทึกไว้ใน `docs/00`
- ผมตัดสินว่าเป้าหลักคือชิ้นงานพอร์ต และยอมรับความเสี่ยงว่าอาจสร้างสิ่งที่ครูไม่ใช้
- `roongern` v0 เสร็จแล้ว และอยากให้ pilot เริ่มได้เร็วในภาคเรียนที่ 2

อ่าน `CLAUDE.md` กับ `docs/05-build-plan.md` อีกรอบ แล้วบันทึกเงื่อนไขข้างบนลง `docs/decision-log.md` (อนุมัติโดย Grape)

**ทำ P1 → P4 ตามลำดับ**
- เริ่มแต่ละเฟสด้วยแผนสั้นๆ (ไฟล์ที่จะสร้าง, ความเสี่ยง, คำถาม) แล้วลงมือได้เลย ยกเว้นเจอเรื่องที่ขัดกับสิ่งที่ล็อก ให้หยุดถามก่อน
- P1: เขียน test D1–D10 ก่อน implement โดยเฉพาะ `review-selection` ตาม `docs/03` §3.3
- P2: ถ้ายังไม่มีค่า Supabase ใน `.env.local` ให้หยุดขอ ห้ามใช้ค่าปลอมที่ทำให้ test ผ่านแบบหลอก
- P3: ข้อความ UI ทั้งหมดมาจาก `src/copy/th.ts` ตามตาราง microcopy ใน `docs/reference/chatgpt-ux-handoff-draft.md` §5 และการเปลี่ยนใน `docs/03` §4
- P4: load test บันทึกเฉพาะตัวเลขที่วัดได้จริง

**จบแต่ละเฟสให้หยุด** แล้วรายงาน: เกณฑ์ผ่านรายข้อ (ผ่าน/ไม่ผ่าน), tested / not tested, commit ที่เกี่ยวข้อง, สิ่งที่ต้องการจากผม แล้วรอผมพิมพ์ "ต่อ P#"

ห้ามทำ P5–P6 ห้ามเรียก AI API ห้าม deploy (เตรียม config กับขั้นตอนไว้ให้ผมกดเอง)
