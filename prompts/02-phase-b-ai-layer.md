# Prompt 02 — Phase B: AI layer + Eval (P5–P6)

ใช้เมื่อ: `docs/00-decision-review.md` บันทึกว่า Gate 1 ผ่านแล้ว **และ** P4 ผ่านแล้ว

---

**ตรวจก่อนเริ่ม:** เปิด `docs/00-decision-review.md` ดูว่ามีบันทึก Gate 1 = ผ่านหรือไม่ ถ้าไม่มีให้หยุดและบอกผม

**ทำ P5 → P6 ตาม `docs/05-build-plan.md`**
- ออกแบบ zod schema และ prompt สำหรับร่างข้อหลัก + มโนทัศน์ ≤ 5 + ข้อทบทวน 1 ข้อต่อมโนทัศน์ ส่งให้ผมดูก่อน implement
- ตรวจ `sourceQuote` แบบ deterministic ก่อนแสดงผล
- ห้ามมี AI call ระหว่าง session และห้ามมีข้อมูลผู้เล่นใน prompt — เขียน test ยืนยัน AI3 และ AI4
- P6: สร้าง eval harness ที่ `eval/` โดยใช้ข้อมูลจริงที่ผมให้เท่านั้น (ห้ามแต่งเอกสารการสอนขึ้นมาเป็น eval set) รายงานผลตาม rubric ใน `docs/01` §8 พร้อมต้นทุนที่วัดได้จริง
- เทียบรุ่นเล็กกับรุ่นกลาง แล้วบันทึกผลและตัวเลือกใน `docs/decision-log.md`

**จบแต่ละเฟสให้หยุด** แล้วรายงาน: เกณฑ์ผ่านรายข้อ, ผล eval, tested / not tested, สิ่งที่ต้องการจากผม

ห้าม deploy และห้ามอ้างผลที่ยังไม่ได้วัด
